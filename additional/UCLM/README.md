# BUS-UCLM experiments

This is an additional breast-ultrasound benchmark that was explored outside the
paper's four main settings (BUSI, BrEaST, QaTa-v1, QaTa-v2).

- `code/` — original training scripts, including UGA-UNet and eight baselines.
- `results/` — the small CSV/report outputs; checkpoints are excluded.

The scripts retain their original hard-coded data paths.  See
[`../README.md`](../README.md) for how to run archived scripts.
