# Figure scripts

The paper's qualitative and diagnostic figures were generated by the original
scripts kept in [`../../reproduce/original/`](../../reproduce/original/):

- `generate_fig5_qualitative.py`
- `generate_fig6_anchor_effect.py`
- `generate_fig7_failure.py`
- `generate_fig8_scatter.py`
- `generate_fig_uncertainty_diagram.py`
- `generate_visualization_sets.py`

Those scripts expect the original result folders and `best_model.pth`
checkpoints, which are not included here.  The final rendered figures are in
[`../../figures/`](../../figures/).
